# Student Management System

A simple Student Management System developed using Python and MySQL.

## Features

- Admin verification
- Add student records
- View all students
- Search students
- Search students by name
- Calculate student grades automatically
- Find students based on marks
- Store student information in MySQL

## Technologies Used

- Python
- MySQL
- SQL
- Object-Oriented Programming (OOP)
- mysql-connector-python

## Grade System

| Marks | Grade |
|------:|:-----:|
| 90–100 | O |
| 80–89 | E |
| 70–79 | A |
| 60–69 | B |
| 50–59 | C |
| 40–49 | D |
| Below 40 | F |

## Database

The project uses MySQL to store student information.

Example fields:

- ID
- Name
- Age
- Marks
- Grade
